# Roadmap

## Planned

### OpenAI TTS Support
Add support for OpenAI TTS models (`tts-1`, `tts-1-hd`, `gpt-4o-mini-tts`) as an alternative provider alongside the current Gemini backend. Users would choose their provider when invoking the skill.

### Expanded Voice Library
Broaden the available voices beyond the current Gemini set — including additional Gemini voices as they become available, and OpenAI's built-in voices (alloy, echo, fable, onyx, nova, shimmer) once OpenAI TTS support lands.

### Saved Custom Styles (Presets)
Let users save narrative styles they create so they don't have to re-describe them every time. A named preset (e.g. `podcast-host`, `bedtime-story`) would be stored locally and offered as an option on subsequent runs. Includes commands to list, apply, and delete saved presets.

## Completed

- Gemini TTS integration with voice and style selection
- OpenCode support
